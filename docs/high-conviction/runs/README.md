# Daily runs

Create one file per completed daily research run: `YYYY-MM-DD.md`.

Each run should contain:
- market/date context,
- portfolio data coverage,
- material changes to held names,
- material changes to high-focus watchlist names,
- new candidates with evidence,
- rejected / false-positive ideas,
- thesis state changes,
- links to sources,
- next checks.

Do not create a daily file full of filler. If nothing material changed, write a concise NO_MATERIAL_CHANGE log with what was actually checked.
